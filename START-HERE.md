# 🚀 CampusShare Pro — Quick Start Guide

## 1. Quick Launch (Windows)
Double-click **`START-WINDOWS.bat`** or run:
```bash
npm start
```
Then open your browser at: **`http://localhost:3000`**

## 3. Recommended Workflow Demonstration (Viva / Project Demo)

1. **Login as Student** (`student@campusshare.com` / `student123`).
2. **Explore Resources**: Search `DBMS`, filter by subject/type, view detail modal, download a file, and click ❤️ to like.
3. **Upload Material**: Go to "Upload Resource", choose a PDF, submit -> Resource goes to **Pending Review**.
4. **Login as Teacher** (`teacher@campusshare.com` / `teacher123` / `FAC-1001`).
5. **Review Upload**: Inspect the pending upload -> Click **Approve (+10 pts)**.
6. **Switch to Student**: Notice **Points increase by +10**, **Campus Rank updates**, and **Achievement progress moves forward**!
7. **Create Assignment / Announcement**: Post from Teacher portal and verify live updates on the Student dashboard.
